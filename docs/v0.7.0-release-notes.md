# CakeSplitter v0.7.0 Local Publication Candidate

CakeSplitter v0.7.0 is a validated, source-only local publication candidate.
It splits files into verified Cake Package 1.0 Slices and rebuilds them
locally, with Windows Desktop, CLI/Batch, and SplitTheCake Web workflows.

## Hardening completed

- machine-readable CLI and Batch schema contracts are aligned across Rust and
  TypeScript;
- public authorship policy is explicitly authorized as Option B and the
  reachable history already matches `Yu-En Huang <enmity.coyotes.3o@icloud.com>`;
- security-contact policy is GitHub private reporting at v0.8;
- release tags remain unsigned until v0.8;
- license, asset-provenance, public-report classification, and artifact policy
  are documented; and
- Web Direct Folder Mode remains disabled fail-closed.

## Validation

Rust formatting, strict Clippy, Rust tests, release build, Node lint,
TypeScript typecheck, 104 Node tests, compatibility tests, Web/Desktop builds,
12 Edge production/privacy/offline tests, npm audits, and RustSec audit passed.
RustSec reported zero vulnerability advisories and 17 accepted upstream
maintenance/unsoundness warnings already documented in the security reports.

## Boundaries

This is not a public GitHub release. There is no remote, download, signed tag,
installer publication, cloud fallback, telemetry, compression, encryption, or
Cake Package authenticity layer. Public GitHub publication remains deferred to
v0.8.0.
