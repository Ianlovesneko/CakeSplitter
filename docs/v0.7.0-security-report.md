# CakeSplitter v0.7.0 Security Report

## Scope and method

The final local-publication review covered Rust core, CLI/Batch, Desktop/Tauri
IPC and capabilities, Web/PWA workers and storage, schemas/validators,
persistence/recovery, receipts/diagnostic export, release configuration, and
public documentation examples. Discovery used repository-wide source and
history inventories plus targeted sink searches. Validation used the existing
production-path regression suites, 12 Edge tests, compatibility harness, and
the full Rust/Node build matrix. Attack-path review traced filesystem,
renderer, worker, persistence, and publication boundaries to their controls.

## Result

No new Critical, High, or actionable Medium finding was validated. Existing
controls cover path traversal, reparse/rebinding, no-replace publication,
bounded allocations and admission, runtime IPC validation, task recovery,
terminal redaction, browser privacy, and exact Rust↔Web package bytes.

The final review found no secret or credential pattern. Path-like matches are
synthetic fixtures and documentation examples only. No network fallback,
telemetry, updater, arbitrary shell capability, or unrestricted filesystem
capability is present in the product boundary. The Desktop Explorer reveal is
reachable only through a short-lived UUID export token issued for a generated
local export.

## Dependency findings

`npm audit` and `npm audit --omit=dev` reported zero vulnerabilities. `cargo
audit` exited successfully with zero vulnerability advisories and 17 accepted
upstream unmaintained/unsound warnings in transitive Tauri/GTK/Unicode tooling;
these are documented and are not silently treated as zero findings.

## Accepted risks

- Cake Package 1.0 has integrity hashes but no publisher authentication,
  encryption, or signatures.
- Browser Compatibility Mode buffers bounded data and remains subject to memory,
  download, and platform limits; Direct Folder Mode is disabled fail-closed.
- Windows filesystem identity and reparse semantics vary by filesystem and
  privilege; ambiguous states fail closed.
- v0.7.0 artifacts and tags are unsigned local previews. Tag signing and
  platform private vulnerability reporting are v0.8 gates.
- Historical detailed reports remain classified until the v0.8 public-history
  decision is completed.
