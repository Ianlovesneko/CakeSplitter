# Public Release Artifact Policy

The `v0.8.1` GitHub pre-release may include only independently validated
artifacts built from the signed release-tag target:

- Windows x64 CLI executable;
- Windows x64 Desktop executable;
- unsigned Windows x64 NSIS current-user installer;
- SplitTheCake Web production static archive;
- `SHA256SUMS.txt` and `artifact-manifest.json`; and
- public installation, limitation, license, notice, security-summary, and
  dependency-inventory material.

Each artifact record must include its version, platform or runtime, type,
architecture, byte size, SHA-256, signing state, validation state, and source
commit. Windows binaries remain unsigned unless an actual Windows code-signing
certificate is independently used and verified. Windows SmartScreen may warn.
Installer binaries may not be bit-for-bit reproducible across toolchains.

Do not publish private bundles, history mappings, raw scan evidence, backups,
logs, receipts, run-state files, browser profiles, test output, or unverified
binaries. Source archives generated by GitHub are sufficient; no extra source
archive is attached.
