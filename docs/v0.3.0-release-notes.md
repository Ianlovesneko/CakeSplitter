# CakeSplitter v0.3.0 Release Notes

CakeSplitter v0.3.0 is an early technical source release of the local-only
SplitTheCake Web App and streaming Rust CLI.

## What it does

- splits one local file into numbered, SHA-256-verified `.slice` files and a
  `.cake.json` manifest;
- inspects and verifies package completeness and Slice hashes;
- rebuilds the original file only after exact verification;
- interoperates between Rust and Web using Cake Package Manifest 1.0;
- supports Slice-size and Slice-count plans, drag/drop, progress, active
  pause/resume, and cancellation;
- records bounded OPFS task metadata, detects interrupted work, guides a safe
  restart, and provides persistence-fenced Clear All; and
- installs as a PWA with a trusted offline static shell.

All browser processing is local. There is no upload, account, analytics,
telemetry, remote checksum, remote error service, or cloud fallback.

## Security hardening

Phase 11 remediated all four validated findings:

- same-size native source mutation and source replacement now fail closed;
- alternate, redirected, unmarked, and opaque responses cannot replace the PWA
  shell;
- Clear All prevents active, delayed, and stale persistence from recreating
  task state; and
- CLI terminal output visibly escapes Unicode bidirectional controls.

No unresolved Critical or High issue remains.

## Validation

- 34 Rust tests passed; formatting, strict Clippy, and release build passed;
- 87 Node/Web tests passed; lint, typecheck, compatibility, and production
  build passed;
- 12 production Microsoft Edge tests passed;
- Rust→Web and Web→Rust boundary matrices matched exact bytes, sizes, and
  SHA-256;
- npm audits reported zero vulnerabilities; and
- RustSec scanned 83 locked crate dependencies with zero advisories.

## Browser limits

Direct Folder Mode is disabled because current browser APIs do not expose
portable atomic no-replace finalization. Compatibility Download Mode is limited
to 256 MiB per Split or Merge, 1,000 Split downloads, and 10,000 selected
package files. Merge buffers the rebuilt Blob. Split buffers one completed
Slice at a time.

Pause/resume applies to a live Worker only. After reload, interrupted work is
reselected and restarted from byte zero; persistent byte resume is not present.

## Compatibility

Application version `0.3.0` continues to read and write Cake Package format
version `1.0`. The format version was not incremented. v0.2.1 packages remain
compatible.

## Install and run

```powershell
npm ci
npm run dev
```

For the CLI:

```powershell
cargo run --locked -p cakesplitter-cli -- --help
```

This is a source-only release. No unverified binaries are attached.

## Not included

CakeSplitter Desktop, queueing, persistent byte resume, plugins, marketplace,
compression, encryption, PAR2, cloud integration, accounts, and AI features do
not exist in this release. Cake Package is a project format, not an industry
standard or authenticated backup format.
