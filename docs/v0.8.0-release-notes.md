# CakeSplitter v0.8.0 — First Public Pre-release

CakeSplitter v0.8.0 is the first public GitHub pre-release of the local-first
Cake Package toolchain. It splits files into verified Cake Package 1.0 Slices,
inspects and verifies packages, and rebuilds the original bytes through
compatible Rust CLI, Windows Desktop, and SplitTheCake Web workflows.

## Included surfaces

- SplitTheCake Web: local Split, Merge, Inspect, Tasks, Compatibility Mode, and
  an offline-capable PWA application shell.
- CakeSplitter Desktop: Windows 10/11 x64 Split, Merge, Inspect, Verify,
  bounded task scheduling, pause/resume/cancel, restart recovery, receipts,
  diagnostics, history, and storage management.
- CakeSplitter CLI: Split, Merge, Inspect, Verify, Plan, Version, Help, human,
  JSON, and JSONL output with stable exit codes.
- Batch workflows: Validate, Plan, Run, Resume, and Status with deterministic
  dependencies, bounded persistent state, and explicit stop policies.

## Security and privacy

Selected file content stays on the user's device. CakeSplitter has no file
upload, telemetry, analytics, Desktop updater, project-managed Web update
endpoint, remote checksum, or cloud fallback. Supporting browsers may perform
same-origin service-worker and static-shell checks during the normal PWA
lifecycle; those requests contain no selected content or task metadata.
Runtime inputs, filesystem identities, task records, and Worker/IPC messages
are validated at their trust boundaries. Output publication is no-replace and
ambiguous native filesystem identity states fail closed.

The public release diff introduced no new network, updater, shell, process, or
arbitrary-filesystem capability. The established path traversal, rebinding,
resource-limit, recovery, terminal-redaction, browser privacy, and
interoperability regression groups remain passing.

## Version boundaries

- Application version: 0.8.0
- Cake Package format: 1.0
- CLI output schema: 1
- Batch Job schema: 1

These are separate compatibility concepts. The portable format and schemas did
not change solely because the application version changed.

## Limitations

- This is early-stage pre-release software, not a backup system or
  authenticated archival format.
- Windows artifacts are x64-only and unsigned. Windows SmartScreen may warn.
- Installer binaries may not be bit-for-bit reproducible across Windows
  toolchain environments.
- Web Compatibility Mode buffers one completed Slice or rebuilt output and is
  constrained by memory, browser download behavior, and platform limits.
- Web Direct Folder Mode remains disabled as a fail-closed security decision.
- Uninstall may preserve bounded local app data.
- Cake Package 1.0 provides SHA-256 integrity but no publisher authenticity,
  digital signatures, encryption, or compression.
- macOS, Linux, and ARM64 are not supported in this release.

Verify every downloaded artifact against `SHA256SUMS.txt`. The `v0.8.0` Git tag
is signed; that tag signature is separate from Windows binary code signing.
