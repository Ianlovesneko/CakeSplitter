## Compatibility and reproducibility

The compatibility harness executes both paths:

1. Rust generates a package; the Web contract and Rust CLI independently rebuild
   it; their bytes and SHA-256 are identical.
2. The Web contract generates a package; Rust verifies/rebuilds it; the Web and
   Rust rebuilt bytes and SHA-256 are identical.

Both validators also reject the shared malicious fixture set. Every successful
rebuild equals the original bytes and declared SHA-256.

## Browser privacy evidence

The production Playwright smoke records requests while selecting local files,
splitting, inspecting, rejecting corruption, and rebuilding. It asserts that no
observed request is a non-GET, has a request body, or includes a selected
filename. Only static application asset GETs are expected. The production CSP
sets `connect-src 'none'`.
