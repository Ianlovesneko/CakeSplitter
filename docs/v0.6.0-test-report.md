## Release boundary

This is a local Windows 10/11 x64 preview release. The installer is unsigned;
SmartScreen may display an unknown-publisher warning. Direct Folder Mode remains
disabled in the Web app. Browser Compatibility Mode may buffer Slice or rebuilt
output data and is subject to browser memory, download, and platform limits.
Files remain local and are not uploaded. Public GitHub publication is deferred
until v0.8.0.
