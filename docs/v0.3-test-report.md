# CakeSplitter v0.3.0 Test Report

Date: 2026-07-17
Host: Windows 11 build 26200; Microsoft Edge 150.0.4078.65; Git 2.52.0;
Rust/Cargo 1.92.0; Node.js 22.18.0; npm 10.9.3.

## Clean environment

`npm ci` replaced the dependency tree from `package-lock.json`, installed 215
packages, audited 220 packages, and reported zero vulnerabilities. `cargo
clean` removed 114.1 MiB before locked dependency fetch. Rust validation used a
fresh target directory outside the repository.

The first strict Clippy attempt using the in-repository `target` directory
exited 1 because dependency build scripts encountered Windows `os error 2`
while creating build-output paths. It emitted no source diagnostic. After
`cargo clean`, the identical Clippy command using a fresh external
`CARGO_TARGET_DIR` exited 0. Tests and release build also passed there. This is
recorded as an environment-path anomaly, not hidden as a passing first attempt.

## Production browser

`npm run test:e2e` uses the production Vite build and desktop Microsoft Edge.
All 12 tests passed with one Worker and no retries required.

Coverage includes:

- Split file selection, drag/drop, Slice-size and Slice-count planning,
  progress, exact Slice hashes, and final manifest;
- Inspect healthy, missing, modified, duplicate, unexpected, unsupported,
  malformed, and unsafe-name packages;
- Merge reordered selection, corruption refusal, exact bytes, and final SHA-256;
- Compatibility Mode memory/download limits before processing;
- pause, resume, cancellation, interrupted-state reload, and safe reselection;
- active Split/Merge Clear All, stale messages, delayed persistence, OPFS
  deletion, reload, and new work after clear;
- simulated OPFS quota failure and fail-closed cleanup;
- PWA static-shell cache, offline startup, and local offline Split;
- no private request, fetch, XMLHttpRequest, WebSocket, EventSource, or
  sendBeacon activity;
- CSP `connect-src 'none'`, keyboard skip navigation, labeled controls, unique
  IDs, focus visibility, and reduced-motion behavior.

Direct Folder Mode is disabled in the real browser. Its fail-closed capability
state and disabled control are covered by production tests; its future
publication contract is covered by 10 unit tests and is not presented as an
available workflow.

## Compatibility

The compatibility harness exercised empty, one-byte, exact-boundary,
final-short, and Unicode multi-extension packages in both runtime directions.
CLI Inspect, Verify, and Merge passed. Every successful rebuild matched exact
size, bytes, and SHA-256. Missing and modified Slices and malicious manifests
were rejected.

The immutable v0.2.1 fixture remains 51 bytes with SHA-256
`d3c3340df8f430c4125ecd46a9af3004a41db1931450890a98cd08bc596e1f6d`
when rebuilt by current Rust and Web contracts.
