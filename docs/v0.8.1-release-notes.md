# CakeSplitter v0.8.1 — Development Toolchain Security Refresh

CakeSplitter v0.8.1 is a narrowly scoped security-maintenance pre-release. It
updates the development-tool dependency chain affected by
[`GHSA-mh99-v99m-4gvg`](https://github.com/advisories/GHSA-mh99-v99m-4gvg).
No product-function, file-format, CLI-contract, privacy-boundary, networking,
Desktop, Web Worker, or browser-filesystem change is intended.

## Why this release exists

After v0.8.0 publication, npm began reporting five High dependency-path
entries rooted in the same `brace-expansion` denial-of-service advisory. Both
affected paths were development-only:

- `eslint@9.39.5` → `minimatch@3.1.5` →
  `brace-expansion@1.1.16`; and
- `typescript-eslint@8.64.0` →
  `@typescript-eslint/typescript-estree@8.64.0` →
  `minimatch@10.2.5` → `brace-expansion@5.0.7`.

`npm audit --omit=dev` reported zero shipped-runtime findings, the production
dependency tree contained no `brace-expansion`, and no product source or
existing Web/Desktop build output referenced the package. There was therefore
no evidence that the affected path was part of shipped CakeSplitter runtime
dependencies. The update is still required to maintain a clean and defensible
development and CI environment.

## Dependency changes

- the direct ESLint requirement moves from `^9.31.0` to `^10.8.0`;
- the resolved ESLint version moves from `9.39.5` to `10.8.0`;
- `@eslint/js` is declared directly at `^10.0.1` because the repository imports
  it directly in `eslint.config.js`;
- the old `minimatch` 3.x / `brace-expansion` 1.x path is removed;
- all remaining toolchain paths resolve through `minimatch@10.2.5` to
  `brace-expansion@5.0.8`; and
- no package override or `npm audit fix --force` is used.

The Node.js requirement is now stated as 20.19+, 22.13+, or 24+ to match the
updated lint toolchain's supported engine range.

## Security result

After the update:

- `npm audit` reports zero vulnerabilities;
- `npm audit --json` reports zero findings at every severity;
- `npm audit --omit=dev` continues to report zero shipped-runtime findings;
- `npm ls brace-expansion --all` resolves only `brace-expansion@5.0.8`; and
- `GHSA-mh99-v99m-4gvg` is absent from the installed dependency graph.

## Compatibility boundaries

- Application version: 0.8.1
- Cake Package format: 1.0
- CLI output schema: 1
- Batch Job schema: 1

Cake Package format 1.0 and the CLI/Batch schemas remain unchanged. v0.8.0,
its signed tag, release assets, checksum files, and GitHub Release remain
immutable.

## Existing product boundaries

CakeSplitter remains local-first and has no selected-content upload, account,
telemetry, analytics, cloud fallback, Desktop updater, remote checksum, or
background service. Web Direct Folder Mode remains disabled as a fail-closed
security decision. Browser compatibility operations remain subject to the
documented memory and download limits.

Windows x64 executables and the installer remain unsigned and may trigger
Windows SmartScreen. Verify every downloaded artifact against
`SHA256SUMS.txt` and the signed checksum file.
