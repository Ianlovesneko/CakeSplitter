# CakeSplitter v0.5.0 Release Notes

CakeSplitter v0.5.0 is a completed local Windows prototype release. Public
GitHub publication is intentionally deferred until v0.8.0.

## Included

- bounded native task queue with priority and fairness;
- conflict detection, resource preflight, pause/resume, cancellation, retry,
  restart recovery, and durable task history;
- local Markdown/JSON operation receipts and redacted diagnostic bundles;
- identity-bound source, package, destination, staged-output, and checkpoint
  handling; and
- Cake Package format 1.0 interoperability with the CLI and Web app.

## Security hardening

The focused v0.5 review found and remediated four actionable Medium findings:
receipt-directory rebinding, diagnostic-directory rebinding, diagnostic path
redaction gaps, and orphaned checkpoint partials. No Critical or High finding
remains. Five bounded Low risks are documented as accepted for this local
prototype; one alias candidate was falsified by native preflight.

## Limitations

This is Windows 10/11 x64 only, with an unsigned preview installer. Direct
Folder Mode remains disabled in the Web app as a fail-closed security decision.
Compatibility browser Split buffers Slice data for download and Merge buffers
rebuilt output; large operations remain subject to memory, download, and
platform limits. Files are processed locally and are not uploaded. CakeSplitter
Desktop is part of this local release; no cloud, account, plugin, compression,
encryption, or package-signature feature is implied.

The application version is `0.5.0`; Cake Package format remains `1.0`.
