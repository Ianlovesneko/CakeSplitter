# CakeSplitter v0.8 Publication Plan

The first GitHub public pre-release is planned for v0.8.0. No remote is
configured and no artifact is published by the v0.7.0 local candidate.

## Required gate

- authorize the repository name and public visibility;
- review branch and authorship policy;
- enable and test GitHub private vulnerability reporting;
- configure and verify release-tag signing;
- complete the full-history/public-root decision;
- rerun secret, private-path, generated-file, license, and security scans;
- validate a fresh clone, installers, artifacts, and checksums;
- publish sanitized public documentation and an unsigned-binary/SmartScreen
  disclosure where applicable; and
- verify the tag and release body before publication.

CakeSplitter remains local-first with no cloud fallback, telemetry, updater,
compression, encryption, or public download before this gate. Cake Package
format 1.0, CLI schema 1, and Batch Job schema 1 remain separate from the
application version.
