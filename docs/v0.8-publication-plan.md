# CakeSplitter v0.8 Publication Plan

`v0.8.0` is the first GitHub public pre-release. The authorized publication
target is `Ianlovesneko/CakeSplitter`, with `main` as the public default branch
and complete validated history preserved.

The publication gate requires a signed `v0.8.0` tag, clean local and public
fresh-clone validation, focused release-diff security review, dependency
audits, checked release artifacts and SHA-256 values, verified GitHub Private
Vulnerability Reporting, and force-push/deletion protection for `main`.

CakeSplitter remains local-first with no cloud fallback, telemetry, analytics,
updater, compression, encryption, or package authenticity signature. Cake
Package format 1.0, CLI schema 1, and Batch Job schema 1 remain independent
from application version 0.8.0.
