# CakeSplitter v0.6.0 Release Notes

CakeSplitter v0.6.0 is a completed local Windows prototype release. Public
GitHub publication is intentionally deferred until v0.8.0.

## Included

- local Split, Merge, Inspect, and Verify workflows in the Web and Windows
  Desktop runtimes;
- a non-interactive Rust CLI with JSON and JSONL output;
- bounded Batch Job schema 1 workflows with deterministic dependencies,
  failure policies, cancellation, resume, and checksummed run state;
- local-only processing with SHA-256-verified Cake Package format 1.0
  interoperability; and
- bounded receipts, diagnostics, resource limits, and identity-aware recovery.

## Validation and security

The final matrix passed Rust formatting, strict Clippy, 146 Rust tests, Node
lint and typecheck, 102 Node tests, Web and Desktop production builds, 12
production Edge tests, Rust-to-Web and Web-to-Rust compatibility, and
dependency audits. npm audits reported zero vulnerabilities. RustSec reported
zero vulnerability advisories and 17 accepted transitive upstream maintenance
warnings.

The focused v0.6 security review found no unresolved Critical, High, or
actionable Medium issue. See
[`v0.6.0-security-report.md`](v0.6.0-security-report.md) and
[`v0.6.0-test-report.md`](v0.6.0-test-report.md).

## Limitations

This is Windows 10/11 x64 only with an unsigned local preview installer.
Direct Folder Mode remains disabled in the Web app as a fail-closed security
decision. Compatibility browser Split buffers Slice data and Merge buffers
rebuilt output; browser memory, download behavior, and platform limits may
impose lower practical limits. Files are processed locally and are not
uploaded. Cake Package 1.0 provides integrity hashes, not authenticity,
encryption, compression, or signatures.

CakeSplitter Desktop is included as a local preview. There is no cloud
integration, account system, plugin marketplace, automatic update service, or
persistent arbitrary-byte resume feature.

The application version is `0.6.0`; CLI schema and Batch Job schema remain `1`,
and Cake Package format remains `1.0`.

## Local installation and source build

Verify the SHA-256 manifest beside the private installer before running it.
The unsigned current-user NSIS installer may trigger a Windows SmartScreen
warning. Source builds require Rust 1.85+, Node.js 20.19+ or 22.12+, npm, the
Windows MSVC build tools, and WebView2. See
[`desktop-installation.md`](desktop-installation.md).
